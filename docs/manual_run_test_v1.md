# Manual Run Test V1

## 1. 目的

用于人工评估 Agent 输出质量，验证结构优化是否真实提升效果。

---

## 2. 评测维度

### 2.1 覆盖性

是否覆盖所有关键动作

---

### 2.2 冗余

是否存在重复问题

---

### 2.3 缺失

是否遗漏关键问题

---

### 2.4 稳定性

多次运行结果是否一致

---

### 2.5 可解释性

是否可以解释问题来源

---

## 3. 判定规则

### open_questions 判定

- 覆盖 ≥ 3个动作 → 合格
- 无重复 → 合格
- 无关键遗漏 → 合格

---

### action_gap_candidates 判定

- 每个 action 必须出现
- gap_type 合理

---

## 4. 输出结论

每个 case 输出：

- pass / partial / fail

---

## 5. 使用方式

用于：

- compare_log 对比
- 决策是否替换 baseline
